# 公文写作（茅台数科定制版）

## 一、核心原则

以公司正式文件为准，不以网络样本代替公司规范。

适用顺序：用户提供的最新正式文件和模板 → 公司较新、较专项的通知 → 公司“三会”规则、议事清单和《制度管理办法》 → GB/T 9704—2012 → 本 Skill 通用写作经验。先读`references/company/来源与适用顺序.md`。

坚持四条底线：

1. 不虚构事实、金额、文号、条款、法律/财务意见、会议决定或审批结果；缺失信息标`【待补充：××】`或`【待确认：××】`。
2. 不以专题办公会替代“三会”决策，不把党委会前置研究写成代替总办会或董事会决定。
3. 不把通用范文的格式、权限、表述直接套入公司材料；具体项目权限须复核完整议事清单。
4. 涉敏议题首页右上角标注“会议资料，会后收回”；正文和附件合并，通过U盘或爱茅台报送，不用QQ、微信传输。

## 三、标准工作流程

### 第1步：明确任务

确认背景、受众/主送、文种、目的、场合和交付形式。涉及经营事项时补充确认金额、资金来源、实施期限、采购方式、前置程序、附件和敏感属性。

只给主题时可先搭骨架，但事实性内容保留待补标记；关键数据冲突时先列冲突请用户定夺。

### 第2步：确定合规路径

上会事项先判会议类型和权限，再选模板；制度事项先判基本/一级/二级/三级/部门级，再确定评审、签批和上会路径。路径不明时明确提示需综合管理部（董事会办公室）确认，不自行类推。

### 第3步：组织素材和提纲

优先采用公司专项模板。收集工作依据、真实进展、数据、意见征求、财务审计审查、法律意见和前置会议纪要。通用讲话稿或事务文书可按“领任务—列提纲—集素材—写正文—善润色—呈定稿”执行。

### 第4步：起草正文

使用庄重、准确、简明的公文语言。开头交代依据，主体突出必要性、可行性、具体方案和预算，结尾写清可表决的提请审议事项或明确工作要求。

上会材料遵守：议题正文原则上≤2000字、汇报类材料≤3000字；“特别汇报事项”无内容则省略；主送和审议事项必须与决策路径一致。

制度文本采用章、节、条、款、项、目结构，条号全文连续，并同步考虑流程和表单。专题纪要保持“会议认为—会议决定—会议要求”，只写真实会议内容。

### 第5步：公司专项自检

逐项检查：

- 文种、主送、决策权限、前置程序和报送时限；
- 金额、资金来源、采购方式、责任部门、完成时限；
- 附件要件、法律/财务意见及其采纳情况；
- 议题/汇报篇幅、敏感标识、正文附件合并和传输要求；
- 字体字号、页边距、行距、层次序号、附件、表格和奇偶页码；
- 所有待补待确认项均已处理或明确保留，不用猜测补齐。

### 第6步：输出与排版

先输出Markdown草稿供确认。用户要求正式Word或已确认排版时，再调用脚本生成.docx；排版阶段只套版式，不擅自改字。

`content.json`选择一种配置：

| profile | 用途 | 正文行距 | 页码 |
|---|---|---|---|
| `meeting` | 上会材料、一般公文正文 | 固定28.95磅，可在28—31磅调整 | “— 1 —”，单页右、双页左 |
| `regulation` | 办法、规定、细则 | 固定31磅，可在28—31磅调整 | “—1—”，单页右、双页左 |

两种配置统一使用A4、上3.7cm/下3.5cm/左2.8cm/右2.6cm、页眉1.5cm/页脚1.75cm、标题方正小标宋二号、正文仿宋GB2312三号、表格宋体小四。

脚本只处理正文和附件，不自动生成红头、正式文号、签发人、印章或版记。正式发文须套用公司模板并履行审批、编号、用印和归档程序。

## 四、Word生成与验收

1. 参照`references/examples/公文报告示例.json`或`references/examples/制度文本示例.json`编写`content.json`。
2. 运行`scripts/build_report.py`生成文档。
3. 运行`scripts/check_format.py`，修复全部FAIL，逐条判断WARN。
4. 用WPS/Word或转换PDF目检标题断行、分页、孤行、表格跨页、附件和奇偶页码。
5. 核对议题属性、审批要件和敏感标识后再交付。

具体字段和命令见`references/出Word格式整理.md`，实现参数见`references/公文报告版式规范.md`。

## 五、公司格式速查

| 要素 | 公司规范 |
|---|---|
| 标题 | 方正小标宋简体二号，居中 |
| 一级标题 | 黑体三号；会议材料用“一、”，制度用“第×章”居中 |
| 二级标题 | 楷体GB2312三号；会议材料用“（一）”，制度用“第×节”居中 |
| 三、四层 | 会议材料依次用“1.”“（1）”，仿宋GB2312三号 |
| 正文 | 仿宋GB2312三号，首行缩进二字符 |
| 制度条 | 条号黑体三号，条后正文仿宋，全文连续编号 |
| 页面 | A4；上3.7、下3.5、左2.8、右2.6cm；页眉1.5、页脚1.75cm |
| 表格 | 一般宋体小四，简洁美观，不超版心 |
| 附件 | 标识黑体三号顶格，标题方正小标宋二号，说明与标题一致 |
| 日期 | 阿拉伯数字写全年月日，不编虚位 |
