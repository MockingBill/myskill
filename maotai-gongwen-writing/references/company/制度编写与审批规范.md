# 公司制度编写与审批规范

依据《贵州爱茅台数字科技有限公司制度管理办法》及其附件整理。起草正式制度时须核对原始PDF。

## 一、先判制度层级

| 层级 | 定位与常用名称 | 基本审批路径 |
|---|---|---|
| 基本管理制度 | 法人治理顶层设计及运营原则，如公司章程、决策机构议事规则 | 党委会前置研究→总经理办公会研究讨论→董事会决定；涉及股东权限的按议事清单继续报批 |
| 一级管理制度 | 决定发展方向、规范某方面工作、明确部门职责和业务关系；通常为《办法》或有关《议事规则》 | 按内容提交党委会、总办会或董事会审议；党建由党委会批准，经营管理由总办会批准，董事会职权由董事会批准 |
| 二级管理制度 | 具体业务环节和核心流程，通常为《规定》 | 重要或较大风险的提级上会；其他可由公司分管领导签批 |
| 三级管理制度 | 实施步骤、方法、检查监督，通常为《细则》 | 原则上分管领导签批；重要或较大风险的提级审议 |
| 部门级制度 | 仅规范部门内部职能、岗位或专项工作 | 不得与公司制度冲突，按部门内部程序审议发布并按要求备案 |

具有决策、决定权的议事规则一般为一级管理制度；仅研究讨论、提供前置依据的议事规则一般为二级管理制度。制度重要程度及是否上会由制度评审会讨论决定，不仅凭名称判断。

仅修订制度名称、部门名称等非实质性内容的，按《制度管理办法》附件6备注执行：经分管领导同意，报综合管理部（董事会办公室）备案即可。正式操作前仍应核对最新审批要求。

## 二、起草内容与结构

完整制度一般包括：

1. 制度基本内容：名称、目的及依据、定义、适用范围、原则、管理机构及职责、主要管理内容、监督、附则等；
2. 制度操作流程：与基本内容配套的流程或IT系统流程；
3. 制度表单：与内容和流程配套的表单。

结构要求：

- 第一章为总则，写明目的、依据、适用范围、原则、术语等；
- 中间章规定机构职责、管理流程、方法、要求、表单和监督检查；
- 最后一章为附则，写明解释主体、实施要求、附件、相关制度关系、生效时间及旧制度废止等；
- 制度名称一般由“公司全称＋管理对象/过程/活动＋制度文体名称”构成；
- 内容须合法合规、符合公司实际，与上位及关联制度协调，结构完整、用语规范、明确严谨。

## 三、章、节、条、款、项、目

- 章、节、条分别写“第×章”“第×节”“第×条”；条号不随章节重新起算，全文连续。
- 条下设款，款不编序号，另起自然段；项用“（一）（二）（三）”，目用“1. 2. 3.”，目下可用“（1）（2）（3）”。
- “第×章”“第×条”后空两个字符；“总则”“附则”两字之间空两个字符。
- 章标题黑体三号、居中；节标题楷体GB2312三号、居中；条号按制度模板用黑体三号，条后正文用仿宋GB2312三号。
- 制度正文每段首行缩进二字符；章、节、表单和流程居中，其他文字两端对齐。

## 四、页面和附件

- 标题：方正小标宋简体二号，固定行距31磅。
- 正文：仿宋GB2312三号，固定行距31磅，可在28—31磅内按排版需要调整。
- A4纵向、不分栏；上3.7cm、下3.5cm、左2.8cm、右2.6cm；页眉1.5cm、页脚1.75cm；每页22行、每行28字。
- 页码奇偶页编码，格式“—1—”，四号宋体；单页居右空一字、双页居左空一字。
- “附件”及顺序号用黑体三号，顶格位于版心左上角第一行；附件标题方正小标宋简体二号，居中位于第三行；附件正文同制度正文。
- 表格内容一般宋体小四；特殊情况字号不作硬性统一，但字体保持宋体且整体简洁美观。
- 附件顺序号、附件说明和附件标题一致，流程图与表单齐全。

## 五、立项、评审和发布材料

制度归口管理单位提出立项申请时，按办法第十七条准备：

1. 制度文本；
2. 征求意见采纳情况表；
3. 修订对照表（修订时）；
4. 起草/修订说明，包括背景目的、过程、主要内容等；
5. 与上位制度、关联制度是否冲突的研判。

起草过程中公开广泛征求意见。涉及员工切身利益的，充分听取工会及员工意见；涉及多部门或跨领域的，征求相关职能部门意见；需征求股份公司纪委或职能部门意见的，按相关规定或授权清单执行。

评审重点包括合法合规、公司实际与管控要求、意见采纳、制度协调兼容、格式与流程表单、廉洁性、适当性与匹配性。未充分征求意见、重大分歧未解决或法律审查存在重大违法违规风险的，应暂缓或终止流程。

评审后按意见修改复审，再按分级权限提请会议审议或领导签发。涉及法律审查意见的制度，发布前向审计法务部书面反馈意见采纳情况。经审批同意发布后，由归口单位审修审校、明确生效时间，综合管理部（董事会办公室）按程序发布并登记备案。

## 六、编号与修订

- 制度编号由公司统一体系管理，示例结构为`Q/SKG02.39-2021`，包含公司制度代码、公司代码、管理制度代号、类别号、顺序号和年代版本号。
- 流程编号由综合管理部（董事会办公室）按《流程管理规定》统一编号；表单按相应通用表格或管控代码统一编号。
- 不自行编造正式制度编号、流程编号或表单编号。
- 每次修订均调整编号；原制度一次修订10处以上，或某一条款累计修订5次以上时，需换版并更改版号；其他修改按规则调整修改码。
- 新旧替代废止时，在新制度中注明旧版同时废止；独立废止按原制定程序审批。

## 七、制度自检清单

- [ ] 层级、名称和审批路径匹配；
- [ ] 第一章总则、最后一章附则，条号全文连续；
- [ ] 机构职责完整但不堆砌常规通用职责；
- [ ] 流程、表单与正文同步设计；
- [ ] 意见征求、修订对照、起草/修订说明和评审材料齐全；
- [ ] 法律审核及意见采纳反馈按事项完成；
- [ ] 章节条格式、页边距、行距、表格、附件和页码符合公司模板；
- [ ] 生效时间、解释部门、旧制度废止表述准确；
- [ ] 正式编号由有权部门确定，不自行补写。
