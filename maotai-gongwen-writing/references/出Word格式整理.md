# 公司公文格式整理与生成 Word

> 内容定稿后再排版。本步只映射结构和版式，不擅自改字；公司红头、文号、签发人、印章和版记须使用正式模板并履行审批，脚本不生成这些要素。

## 1. 选择文档配置

| 配置 | 用途 | 正文行距 | 页码 |
|---|---|---|---|
| `meeting`（默认） | 上会请示、报告、一般公司公文正文、专题纪要正文 | 固定28.95磅，可在28—31磅调整 | “— 1 —” |
| `regulation` | 办法、规定、细则等制度文本 | 固定31磅，可在28—31磅调整 | “—1—” |

两种配置均为A4纵向，上3.7cm、下3.5cm、左2.8cm、右2.6cm，页眉1.5cm、页脚1.75cm，奇数页码居右空一字、偶数页码居左空一字。

## 2. 选择内容入口

| 输入 | 操作 |
|---|---|
| 纯文字/Markdown/对话定稿 | 编写`work/content.json` |
| 已有docx只改版式 | 用`extract_docx.py`盘点段落、表格和图片，再编写JSON |
| 扫描件/PDF | 先OCR并校对，再映射JSON；不得把OCR错字直接带入成稿 |

```bash
SKILL="/path/to/ydxc0511-1.2.11"  # 替换为实际Skill目录
python "$SKILL/scripts/extract_docx.py" 来源.docx -o work/media
```

## 3. content.json 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `profile` | 否 | `meeting`默认；制度写`regulation` |
| `title` | 是 | 字符串或数组；长标题按语义分行，不用空格凑对齐 |
| `recipient` | 否 | 主送机关或会议，脚本自动补全角冒号 |
| `body` | 是 | 正文块数组 |
| `signer`/`date` | 否 | 署名、成文日期；`auto`使用当天 |
| `attachments` | 否 | 附件数组，自动生成附件说明和附件页 |
| `numbering` | 否 | 默认`auto`；须保留原编号时设`manual` |
| `sensitivity` | 否 | 敏感议题填`会议资料，会后收回`，置于首页右上角 |

### 一般公文正文块（meeting）

- `p`：普通正文，支持`**加粗**`；
- `h1`：一级标题“一、”，黑体三号；
- `h2`：二级标题“（一）”，楷体GB2312三号；
- `h3`：三级标题“1.”，仿宋GB2312三号；
- `h4`：四级标题“（1）”，仿宋GB2312三号；
- `table`：表格；`blank`：空行；`pagebreak`：分页。

### 制度正文块（regulation）

- `chapter`：章标题，自动连续编号“第X章”，黑体三号居中；
- `section`：节标题，自动编号“第X节”，楷体GB2312三号居中；
- `article`：条，自动全文连续编号“第X条”，条号黑体、内容仿宋；
- `p`：款或普通正文；项、目分别在文本中使用“（一）”“1.”“（1）”；
- `table`、`blank`、`pagebreak`同前。

`chapter`的`text`只写章名，如“总则”；`article`的`text`只写条内容，不重复输入条号。`manual`模式下保留原文，不自动增删编号。

示例：`references/examples/公文报告示例.json`、`references/examples/制度文本示例.json`。

## 4. 结构硬规则

1. 一般公文层次为“一、→（一）→1.→（1）”，第三、第四层不得误用楷体或重复使用“（一）”。
2. 制度条号全文连续，章、节居中；“总则”“附则”按公司模板留字间空位。
3. 不用空格做首行缩进，不给黑体/楷体标题额外加粗，不保留Word默认标题的蓝色、边框和主题字体。
4. 附件说明与附件页序号、标题一致，每件附件另页起排并连续编页码。
5. 表格默认宋体小四、全框线，总宽不超过15.6cm版心；特殊表格可调整字号，但保持简洁美观。

## 5. 生成与验收

```bash
python "$SKILL/scripts/build_report.py" work/content.json -o output/材料名称_2026-11-10.docx
python "$SKILL/scripts/check_format.py" output/材料名称_2026-11-10.docx
soffice --headless --convert-to pdf output/材料名称_2026-11-10.docx --outdir output/pdf
```

- `check_format.py`必须0 FAIL；WARN逐条判断。
- 使用WPS/Word或PDF目检标题断行、孤行、表格跨页、附件起页、空白页和奇偶页码。
- 无公司字体时，PDF仅用于结构目检；文档保留规范字体名，在公司办公电脑复核字形。
- 文件名使用日期或版本号，不使用“final”“终版”等不可追踪名称。
